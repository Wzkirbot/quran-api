## Reporting a Vulnerability

We take the security and integrity of the Quran API seriously. If you discover a security vulnerability (such as an injection flaw, denial-of-service, or information disclosure), please do **NOT** open a public issue on GitHub.

Instead, please send an email to the repository maintainer with:
- A description of the vulnerability.
- Steps or a proof-of-concept to reproduce the issue.
- Potential impact and mitigation recommendations.

We will review reports within 48 hours and work with you on a responsible disclosure and patch release.
