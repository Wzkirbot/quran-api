Architecture & Philosophy

Built for Reliability, Speed & Autonomy

🛡️

Self-Hosted & Offline-First

No runtime external API dependencies. All requests are served strictly from your local PostgreSQL database and fast dual-layer cache.

📖

Verified Religious Datasets

114 Surahs, 6,236 Ayahs (Uthmani & Simple scripts), 30 Juz, 604 Pages, plus authentic Adhkar from Hisn al-Muslim, Duas, and Al-Muyassar Tafsir.

⚡

High-Performance & Dual Cache

Optimized PostgreSQL B-Tree and GIN Trigram indexes for instant Arabic search. In-Memory LRU Cache with seamless automatic Redis integration.

🔒

Production Hardened

Equipped with configurable Rate Limiting, Helmet security headers, CORS protection, SQL injection prevention, and standardized error envelopes.

🐳

One-Command Docker Setup

Clone and run with Docker Compose in seconds. Complete automated database migrations and seeder scripts ready out of the box.

📜

100% Free & Open Source

Published under the permissive MIT License with transparent attribution manifests, checksums, and zero tracking or user data collection.
